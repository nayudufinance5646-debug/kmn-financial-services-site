KMN FINANCIAL SERVICES — SIMPLE STATIC WEBSITE
================================================

FILES
- index.html       Main mobile-friendly website
- styles.css       Responsive design, brand colours
- script.js        Small year display helper
- privacy.html     Privacy policy draft
- terms.html       Terms and disclaimer draft
- Promotional SVG illustrations are embedded directly in index.html (no image folder upload required)
- CNAME            Custom domain placeholder; use only after you own/verify the domain

IMPORTANT
This package creates website files only. It does not register the domain, create a hosting account, or publish the site. Availability of kmnfinancialservices.in has not been checked. Do not claim the site is live until it is tested at the registered domain.

BEFORE PUBLICATION
1. Confirm domain availability and register it in an account you control.
2. Review the privacy policy and terms against actual partner contracts, data collection and applicable law.
3. Verify POS authorization, DSA scope and Softzix arrangement before advertising the relevant services.
4. Keep Banking BC/BF marked “Coming Soon” until required bank/corporate appointment, authorization and activation are complete.
5. Do not add bank or insurer logos without permission.
6. Do not add a public form that collects Aadhaar, PAN, account/card details, OTPs, PINs or passwords.
7. This version uses direct phone, email and WhatsApp links. It does not store form submissions or collect information through a website form.

LOW-COST HOSTING OPTION: GITHUB PAGES
GitHub Pages can host static website files. A custom domain requires a domain you control, DNS setup and HTTPS configuration. Follow the current official docs:
https://docs.github.com/en/pages
Custom domain guide:
https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site
HTTPS guide:
https://docs.github.com/en/pages/getting-started-with-github-pages/securing-your-github-pages-site-with-https

DEPLOYMENT STEPS
1. Create/sign in to a GitHub account you control.
2. Create a new public repository, for example kmn-financial-services-site.
3. Upload index.html, styles.css, script.js, privacy.html and terms.html to the repository root.
4. Replace index.html and styles.css with the updated versions from this ZIP.
5. Open repository Settings > Pages and configure deployment from the main branch/root following the current GitHub instructions.
6. Test the generated github.io URL on a mobile phone.
7. After registering and verifying the domain, add the custom domain in Pages settings and follow the exact DNS instructions shown by GitHub and your registrar.
8. Enable “Enforce HTTPS” when available. DNS and certificate activation may take time.
9. Test the domain, phone/email/WhatsApp links and legal pages.
10. Enable domain auto-renewal and account two-factor authentication.

SECURITY
- This is a static information site, not a secure customer portal.
- Never put passwords, secret keys, customer data or certificate scans with personal information in the public repository.
- Use unique passwords and two-factor authentication.
- Keep repository files free of sensitive customer information.
- HTTPS encrypts the connection; it does not make a static website appropriate for collecting sensitive financial data.
